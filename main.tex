\section{Conjuntos}

Los conjuntos, tanto en las matemáticas como en la física, son muy importantes, nos ayudan a etiquetar objetos que tienen algo en común. Podemos tener conjuntos de números, objetos físicos, objetos abstractos, etc. En general definimos a un conjunto como una colección de objetos, algunas de estas colecciones pueden tener una regla en particular, como lo son el conjunto de números enteros entre el $3$ y el $6$ $\{3,4,5,6\}$, podemos describir a un conjunto usando la siguiente forma

\[
C=\{ \text{ (forma del elemento) }| \text{ (que cumple con cierta regla) }\}
\]

Usamos la notación $\in$ que indica \colorbox{Green}{pertenencia} es decir, un elemento $a\in C$ nos dice que $a$ es parte del conjunto $C$. También podemos negar esta operación con hacer $\notin$. 

¿Qué pasa cuando nuestro conjunto no tiene elementos? En este caso decimos que el conjunto es \colorbox{Green}{vacío} $\varnothing$. Este conjunto está dentro de todos los conjuntos $\forall C$ $\varnothing \in C$.

Usando el mismo razonamiento de antes decimos que existe un conjunto que contiene a todos los demás, a este conjunto lo llamamos conjunto \colorbox{Green}{universo/universal} y lo denotamos con $U$.

Con estas herramientas podemos definir el complemento de un conjunto $A^c$ como el conjunto de elementos que no estén dentro de nuestro conjunto $A$, es decir

\[
A^c=\{x\text{ }| \text{ }x\notin A\}
\]

\subsection{Operaciones con conjuntos}

Como a la mayoría de los objetos matemáticos que nos interesan, los conjuntos también se pueden operar entre sí, parecido a las operaciones clásicas que todos conocemos como la suma y la resta, a los conjuntos podemos operarlos de diferentes formas

Decimos que $B$ es subconjunto de $A$ si cada elemento de $B$ es un elemento de $A$.

\begin{itemize}
    \item \textbf{Unión}: Definimos a la unión de dos conjuntos con el operador $\cup$. Esta operación combina ambos elementos de los dos conjuntos en uno más grande.
    \item \textbf{Intersección}: Definimos a la intersección de dos conjuntos con el operador $\cap$. Lo que hacemos es que solamente tomamos a los elementos en común entre ambos conjuntos.
\end{itemize}

Ambas operaciones cumplen con estas dos identidades importantes conocidad como \colorbox{Green}{leyes distributivas}.

Sean $A$, $B$ y $C$ conjuntos, entonces

\begin{enumerate}
    \item $A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$.

    \item $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$.
\end{enumerate}


Dos conjuntos $A$ y $B$ son iguales si $A\subseteq B$ y $B \subseteq A$ 

Después de definir todo esto, surgen muchísimas propiedades al operar dos o más conjuntos, la lista de las más importantes es la siguiente.

Sean $A$, $B$ y $C$ conjuntos. Sus propiedades de \colorbox{Green}{unión} son

\begin{enumerate}
    \item $A \subseteq A \cup B$; $B \subseteq A \cup B$.

    \item $A = A \cup \varnothing$; $A \cup A = A$.

    \item $(A \cup B) \cup C = A \cup (B \cup C)$.

    \item $A \cup B = B \cup A$.

    \item $A \cup B = B$ si y solo si $A \subseteq B$.
\end{enumerate}

Y sus propiedades con \colorbox{Green}{intersección} son

\begin{enumerate}
    \item $A \cap B \subseteq A$; $A \cap B \subseteq B$.

    \item $A \cap \varnothing = \varnothing$; $A \cap A = A$.

    \item $(A \cap B) \cap C = A \cap (B \cap C)$.

    \item $A \cap B = B \cap A$.

    \item $A \cap B = A$ si y solo si $A \subseteq B$.
\end{enumerate}

También existen propiedades adicionales. Sean $A$, $B$ y $C$ conjuntos.

\begin{enumerate}
    \item Si $A \subseteq B$, entonces $A \cup C \subseteq B \cup C$.

    \item Si $A \subseteq B$, entonces $A \cap C \subseteq B \cap C$.

    \item Si $A \subseteq C$ y $B \subseteq C$, entonces $A \cup B \subseteq C$.

    \item Si $C \subseteq A$ y $C \subseteq B$, entonces $C \subseteq A \cap B$.
\end{enumerate}

Así como en el álgebra de números, en el álgebra de conjuntos podemos restar conjuntos, aunque no en el sentido clásico, por eso le llamamos \colorbox{Green}{diferencia} y la definimos como

\[
A-B=\{x\text{ }| \text{ } x \in A \text{ y } x \notin B\}
\]

Tiene cuatro propiedades importantes. Sean $A$ y $B$ conjuntos, entonces

\begin{enumerate}
    \item $A - A = \varnothing$; $A - \varnothing = A$.

    \item $A - B \subseteq A$.

    \item $(A - B) \cap B = \varnothing$.

    \item $A - B = A$ si y solo si $A \cap B = \varnothing$.
\end{enumerate}

Con lo que llevamos podemos definir dos propiedades muy importantes de toda el álgebra de conjuntos, las famosas \colorbox{Green}{Leyes de Morgan}. Sean $A$, $B$ y $C$ conjuntos, entonces

\begin{enumerate}
    \item $A - (B \cup C) = (A - B) \cap (A - C)$.

    \item $A - (B \cap C) = (A - B) \cup (A - C)$.
\end{enumerate}

\section{Espacios Vectoriales}

En la física trabajamos mayormente con números reales y complejos, por eso solo nos concentraremos en esos dos conjuntos. Ahora consideramos un subconjunto $F$ de $\mathbb{C}$. Decimos que $F$ es un \colorbox{Green}{campo} si cumple con lo siguiente

\begin{itemize}
    \item Sean $x,y$ elementos de $F$, entonces $x+y$ y $x\cdot y$ también son elementos de $F$
    \item Sean $x\in F$, entonces $-x$ también es un elemento de $F$, más aún, si $x\neq 0$ entonces $x^{-1}\in F$.
    \item Tanto el $1$ como el $0$ son elementos de $F$.
\end{itemize}

Podemos concluir que tanto $\mathbb{R}$ como $\mathbb{C}$ son campos.

A los elementos de un campo se les llama escalares.

Un \colorbox{Green}{espacio vectorial} $V$ sobre un campo $F$ es un conjunto de elementos que pueden ser sumados entre si y multiplicados por elementos de $F$, de tal manera que la suma y la multiplicacion por escalar caen dentro de $V$, también deben cumplir con las siguientes propiedades

\begin{itemize}
    \item \textbf{(VS 1)} (Conmutatividad de la suma) Para cualquier $u,v\in V$ tenemos que
    \[
    u+v=v+u
    \]
    \item \textbf{(VS 2)} (Asociatividad de la suma) Dados cualesquiera tres elementos $u,v,w$ de $V$, estos cumplen
    \[
    (u+v)+w=u+(v+w)
    \]
    \item \textbf{(VS 3)} (Existencia del neutro aditivo) Existe un elemento de $V$, al que denotamos con $0$ tal que
    \[
    0+u=u+0=u
    \]
    para cualquier elemento $u$ de $V$.
    \item \textbf{(VS 4)} (Existencia del inverso aditivo) Dado un elemento arbitrario $u$ de $V$, existe un elemento $-u\in V$ tal que $u+(-u)=0$
    \item \textbf{(VS 5)} (Existencia del neutro mutiplicativo) Para todo elemento $u\in V$ y el número $1\in F$, tenemos que 
    \[
    1\cdot u =u
    \]
    \item \textbf{(VS 6)} Sean $a,b\in F$, entonces
    \[
    (ab)\cdot u = a \cdot (bu)
    \]
    \item \textbf{(VS 7)} Sea un escalar $c$, entonces
    \[
    c\cdot(u+v)=cu+cv
    \]
    \item \textbf{(VS 8)} Sean los escalares $a,b\in F$, entonces
    \[
    (a+b)\cdot u= au+bu
    \]
    
    
\end{itemize}

\subsection{Números Complejos}

Definimos a un número complejo como una pareja ordenada $(a,b)$, donde tanto como $a,b\in$ $\mathbb{R}$. A diferencia de un espacio vectorial como $\mathbb{R}^2$, escribimos a esta pareja como $a+ib$.

Podemos describirlo como un conjunto
\[
\mathbb{C}=\{a+ib \text{ }  | \text{ } a,b\in \mathbb{R}\}
\]

Definimos dos operaciones, la suma y la multiplicación
\[
(a+ib)+(c+id)=(a+c)+i(b+d)
\]
\[
(a+ib)\cdot(c+id)=(ac-bd)+i(ad+bc)
\]


Vemos que, al igual que los números reales $\mathbb{R}$, los números complejos $\mathbb{C}$ también son un espacio vectorial. Solo que le añadimos la propiedad adicional \colorbox{Green}{$i^2=-1$}.

Entonces, los números complejos tienen las siguientes propiedades

\begin{itemize}
    \item \textbf{Conmutatividad}
    \[
    a+b=b+a \text{ }\text{ y }\text{ } ab=ba \text{ }\text{ } \forall a,b\in \mathbb{C}
    \]
    \item \textbf{Asociatividad}
    \[
    (a+b)+c=a+(b+c) \text{ }\text{ y } \text{ } (ab)c=a(bc) \text{ }\text{ } \forall a,b,c\in\mathbb{C}
    \]
    \item \textbf{Identidad}
    \[
    a+0=a \text{ } \text{ y } \text{ } a\cdot 1=a \text{ }\text{ } \forall a\in \mathbb{C}
    \]
    \item \textbf{Inverso aditivo}
    \[
    \text{Para cada} \text{ } a\in\mathbb{C} \text{ } \text{existe un único } b \in \mathbb{C} \text{ tal que } a+b=0
    \]
    \item \textbf{Inverso multiplicativo}
    \[
    \text{Para cada } a \in \mathbb{C} \text{ diferente de cero, existe un único } b\in \mathbb{C} \text{ tal que } ab=1
    \]
    \item \textbf{Distributividad}
    \[
    c(a+b)=ca +cb \text{ } \text{ } \forall a,b,c\in \mathbb{C}
    \]
\end{itemize}
